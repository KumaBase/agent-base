# rules/

ここは **あなたの組織・個人のルール置き場** です。

AgentBase 共通の上位ルールは `core/rules/` にあります。この `rules/` 配下は、導入先ごとに自由に編集・追加できます。

## 階層

| パス | 役割 |
|---|---|
| `company/` | 会社・組織全体の方針 |
| `clients/` | 顧客ごとの制約 |
| `projects/` | 案件・成果物ごとの進行ルール |
| `teams/` | チーム・部門の実務ルール |
| `personal/` | 個人の作業スタイル |
| `tasks/` | 今回限りの個別指示（必要時のみ） |

## 初回セットアップ

AI に **「セットアップして」** と依頼すると、`core/templates/` から雛形をコピーし、ここに Company Rule / Personal Rule が生成されます。

## テンプレート

雛形は `core/templates/` を参照してください。直接編集せず、ここにコピーしてから記入します。
