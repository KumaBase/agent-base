# SELF_HEAL.agent.md

AI エージェント向け指示書。セッション開始時、または利用者が **「健康診断して」** と依頼したときに参照する。

---

## 役割

`core/.agent-base-lock.json` と現ファイルを照合し、中核領域の改変を検出・修復する。

## 手順

### 1. lock を読む

`core/.agent-base-lock.json` が未生成（`version: null`）の場合:

- 「セットアップ未完了です。セットアップして、と依頼してください」と返す

### 2. managed 領域を照合

`managed_file_hashes` と `core/` 配下の現ファイル sha256 を照合する。

- 全一致 → managed 領域は **正常**
- 不一致 → ファイルごとに以下を提示:
  1. **復元**: Releases から元バージョンを取得して上書き
  2. **退避**: 改変内容を `rules/` 配下（例: `rules/tasks/`）へ移し、`core/` を復元
  3. **一時許可**: 今回はそのまま（次回も警告）

### 3. root 雛形を照合

`root_template_hashes` との不一致は **警告レベル**（利用者所有のため）。

- 改変済みであることを伝える
- 更新時にマージが必要になる旨を案内

### 4. 結果レポート

- 正常 / 要修復 の件数
- 修復したファイル
- 残った差分
- 推奨アクション

---

## 原則

- `core/` の改変は修復対象。利用者の意図的カスタムは `rules/` へ誘導する。
- 復元前に、失われる改変内容の要約を必ず示す。
